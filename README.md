# Library & Event Management System (MVC)

## 📌 Project Overview
This is a **Library and Event Management System** built using the **MVC architecture**.
The system manages library operations as well as posts/events with a clean separation
of concerns between Models, Views, and Controllers.

## 🛠️ Tech Stack
- Node.js
- Express.js
- EJS (Embedded JavaScript)
- MongoDB + Mongoose
- MVC Architecture
- HTML, CSS, JavaScript

## ✨ Features
### 📚 Library Management
- Add, update, delete books
- Manage library records
- Structured MVC flow

### 📢 Event / Post Management
- Create and manage events/posts
- Media support
- Dynamic rendering using EJS
